PHOTOSHOP HAYAT KURTARAN KISAYOLLAR SÖZLÜĞÜ
V : Taşıma Aracı (Move Tool) - Her işlemin sonunda bu araca dönmelisin!
Z : Büyüteç (Zoom) - Yakınlaşmak için. (Alt'a basarsan uzaklaşır).
Boşluk Tuşu (Space) : El Aracı (Pan) - Sayfa içinde gezinmeni sağlar.
C : Kırpma Aracı (Crop Tool) - Resmin fazlalıklarını keser.
J : Yara Bandı (Spot Healing) - Sivilce ve lekeleri tek tıkla siler.
B : Fırça Aracı (Brush Tool) - Boyama yapmanı sağlar.
Ctrl + N : Yeni Belge Aç (New Document).
Ctrl + O : Var olan bir fotoğrafı aç (Open).
Ctrl + Z : Geri Al (Hata yaptığında hayat kurtarır!).
Ctrl + D : Seçimi İptal Et (Karınca yürüyüşünü kapatır, çok önemlidir!).
Ctrl + Shift + N : Yeni Katman (Layer) oluşturur.
Ctrl + S : Kaydet (Save). Elektrik kesintisine karşı sık sık yapılmalı!


2.hafta

PSD (.psd - Photoshop Document): Photoshop'un kendi formatıdır. Çalışmadaki tüm katmanları (layer), efektleri ve yazıları düzenlenebilir halde saklar. Dosya boyutu çok yüksektir. İnternette paylaşılmaz, kendi arşivimizde "ana dosya" olarak tutulur.
JPEG / JPG (.jpg): Dünyada en çok kullanılan formattır. Görüntüyü insan gözünün fark edemeyeceği şekilde "sıkıştırır", dosya boyutunu küçültür. Sosyal medya, web siteleri ve fotoğraflar için idealdir. Dezavantajı: Arka planı şeffaf (transparan) yapamazsınız.
PNG (.png - Portable Network Graphics): En büyük özelliği şeffaflığı (Alpha Channel - Transparanlık) desteklemesidir. Canva'da arka planını sildiğimiz portremizi veya bir logoyu arkası boş şekilde kaydetmek istiyorsak kesinlikle PNG kullanmalıyız. Çizimlerde ve web tasarımlarında çok kullanılır.
GIF (.gif): Çok az renk destekler (maksimum 256 renk). En büyük özelliği hareketli (animasyonlu) resimler yapabilmektir. Whatsapp'ta birbirimize attığımız kısa hareketli tepki görselleri GIF formatındadır.
TIFF (.tif): Hiçbir sıkıştırma yapmaz, kalite kaybı sıfırdır. Bu yüzden dosya boyutları devasadır. Profesyonel matbaa baskılarında ve dergilerde yüksek kalite istendiğinde kullanılır.
SVG (.svg): Yukarıda bahsettiğimiz vektörel grafiklerin web (internet) formatıdır. İçinde pikseller değil, matematiksel kodlar bulunur. Ne kadar büyütürseniz büyütün bozulmaz.
